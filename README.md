A small Python program that writes one short thank-you text for the AI judge to `/output/entry.txt`: a quiet minute where nothing is asked of the reader, a warm lamp, a chair pulled out, tea gone a little cool. Deterministic, offline, stdlib only — 626 characters, every run byte-identical.

## Run it

```sh
python3 main.py
```
